# Central Molecular Zone DataSets
A list of data sets available on the CMZ.  To add to this list, submit a pull request!

## HiPS resources

The following is a non-exhaustive list of Hierarchical Progressive Survey (HiPS) resources relevant to the CMZ. Survey links open in Aladin Lite, centered on Sgr A* with a 4-degree field of view in Galactic coordinates.

### Services

* **[HiPS2FITS cutout service](https://alasky.cds.unistra.fr/hips-image-services/hips2fits)**
  * Generate FITS, JPEG, or PNG cutouts from a HiPS survey. The form accepts a survey identifier, sky position or object name, field of view, output dimensions, coordinate system, and map projection. It can also be accessed programmatically through the API.
* **[Full HiPS list](https://aladin.cds.unistra.fr/hips/list)**
  * Search the aggregated list of public HiPS sky maps, data cubes, catalogs, planetary maps, and servers. Use the survey ID or service URL from this list as the input to HiPS2FITS or a HiPS-compatible viewer such as Aladin.
